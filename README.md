Welcome to the Kryptos Browser v3.1.0!

This is the biggest update yet, featuring a complete UI overhaul, advanced privacy features, and a massive performance boost.

What's New in V3.1.0:
- New Hacker/Sci-Fi UI: Deep matte black theme with vibrant neon green accents and an ambient glowing fingerprint logo.
- Real-Time Tracker Blocker: Live counter showing how many trackers and ads were blocked.
- Auto Speed Dial: Your most visited websites now automatically appear on the homepage.
- History & Bookmarks: Fully functional local SQLite databases to manage your browsing data.
- Download Manager: Seamlessly download files with native Android support.
- Auto Cache Cleaner: App cache automatically clears when it exceeds 100MB to save storage.
- Custom Dark Popups: All menus and dialogs now match the dark theme perfectly.
- Custom App Icon: New Fire logo for your home screen.
- Google CAPTCHA Fix: Updated User-Agent for smoother searches.
- Backend Fixes: Fixed auto-updater, back button behavior, and address bar clearing.

Important Note:
Because we changed the app's digital signature for the Auto-Updater to work correctly, you MUST uninstall any previous version of Kryptos Browser before installing this one. Future updates will work seamlessly without uninstalling!
